# CAP's Pizza & Tap House Website

Official website for CAP's Pizza & Tap House in Sacramento, CA.

## File Structure
├── index.html
├── menu.html
├── trivia.html
├── README.md
├── styles.css
├── script.js
├── site.webmanifest
├── images/
│ ├── logo.png
│ ├── CAPs-Pizza-Hero.jpg
│ ├── apple-touch-icon.png
│ ├── favicon-32x32.png
│ └── favicon-16x16.png
└── pdf/
└── CAPs-Menu-2024.pdf

## Pages

- `index.html` - Home page
- `menu.html` - Menu page with PDF viewer
- `trivia.html` - Information about weekly trivia nights

## Assets

### Stylesheets
- `styles.css` - Custom styles
- Tailwind CSS (loaded via CDN)

### JavaScript
- `script.js` - Main JavaScript file (handles mobile menu functionality)

### Images
- `logo.png` - Main restaurant logo
- `CAPs-Pizza-Hero.jpg` - Hero image used in headers
- Various favicon and touch icons

### Documents
- `CAPs-Menu-2024.pdf` - Current menu in PDF format

## Features

- Responsive design
- Mobile-friendly navigation
- PDF menu viewer with download option
- Google Analytics integration
- Social media links (Facebook, Instagram)
- Online ordering integration
- Contact information and business hours
- Interactive map directions

## Development

This site uses:
- HTML5
- Tailwind CSS for styling
- Vanilla JavaScript
- Google Analytics for tracking
